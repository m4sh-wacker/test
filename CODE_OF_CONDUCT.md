# Code of Conduct

OWASP DecodeBox is an OWASP Foundation project and follows the
**[OWASP Code of Conduct](https://owasp.org/www-policy/operational/code-of-conduct)**.

In short: everyone participating in this project — in issues, pull requests, discussions, and any
project space — is expected to be respectful, constructive, and professional. Harassment,
personal attacks, and discriminatory behaviour are not tolerated.

## Reporting

If you experience or witness behaviour that violates the Code of Conduct, report it to the project
lead. If the concern involves the project lead, or you would rather raise it outside the project,
contact the OWASP Foundation directly per the process described in the linked policy.

Reports are handled confidentially.
